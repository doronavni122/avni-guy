# indexnow_oneshot (after production deploy)
in1: Confirm production INDEXNOW_KEY set in Vercel (empty = skip)
in2: Dry-run first (no live claim):
  INDEXNOW_ONESHOT_TOP20=1 node scripts/post-deploy-indexnow.mjs
  expect: mode=top20-oneshot; dry-run or skip if key unset
in3: Live oneshot (owner machine or CI with secrets):
  INDEXNOW_KEY=$INDEXNOW_KEY INDEXNOW_PING=1 INDEXNOW_ONESHOT_TOP20=1 SITE_URL=https://avniguy.co.il node scripts/post-deploy-indexnow.mjs
  expect logs: batch-ok or batch-fail; only batch-ok counts as ping success
in4: Full postbuild (already in package.json postbuild) uses mode=full when INDEXNOW_ONESHOT_TOP20 unset
in5: Artifact: .next/indexnow-last-run.txt (livePing + batchesOk)
